RISC-V MCU

A 5-stage pipelined RISC-V processor implemented in SystemVerilog and physically verified on a Basys 3 FPGA.

The processor includes an M Extension, FPU, 2-bit branch predictor, and L2 pseudo-LRU cache.

SerDes Labs for CARP

Educational SerDes labs designed to teach digital communication concepts and introduce students to professional ASIC development tools.

The labs cover RTL simulation, synthesis, gate-level simulation, place and route, parasitic extraction, and eye diagram analysis.

FPGA Dynamic Function Exchange

Dynamic Function Exchange implemented on a Basys 3 FPGA using multiple reconfigurable Pblocks.
