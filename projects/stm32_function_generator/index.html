STM32 Function Generator

Register-Level Embedded Waveform Generator

Built a programmable function generator using an STM32 NUCLEO-L476RG, an external 12-bit DAC, and a matrix keypad. The system generates sine, triangle, sawtooth, and square waves while allowing the user to change frequency and square-wave duty cycle during operation.

Project Overview

The project was developed primarily through low-level register-based firmware rather than relying entirely on high-level peripheral libraries. TIM2 provides deterministic waveform sample timing, while SPI transfers digital samples from the STM32 to the external DAC in real time.

Timer Driven Sampling

Configured TIM2 interrupts to control DAC update timing instead of using software delays. The timer generates a fixed sample rate while firmware tracks the current waveform position.

SPI DAC Interface

Configured SPI1 at the register level to send 12-bit waveform samples to an external DAC. Each timer interrupt calculates the next voltage sample and immediately updates the DAC.

Matrix Keypad

Implemented matrix keypad scanning using GPIO rows and columns. The keypad allows waveform type, output frequency, and square-wave duty cycle to be changed while the generator is operating.

Hardware Verification

Verified generated waveforms with an oscilloscope by measuring waveform shape, output frequency, voltage range, and square-wave duty cycle.

Hardware Flow

STM32 TIM2 ISR calculates waveform samples
→
SPI Transfers 12-bit digital samples
→
DAC Converts samples into analog voltage

Waveform Generation

Sine

Uses a 32-entry lookup table containing precomputed voltage samples.

Triangle

Generates a linear ramp upward followed by a linear ramp downward across each waveform period.

Sawtooth

Continuously increases the DAC sample voltage before resetting at the end of the period.

Square

Alternates between high and low output values with an adjustable duty cycle.
