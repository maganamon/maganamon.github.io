Come to Pawpa

Top-Down 2D Shooter

Come to Pawpa is a top-down 2D shooter developed in the Godot Engine as part of a three-person team. I served as the lead programmer, implementing the game's core logic, mechanics, and gameplay systems.

About the Project

The game follows a father cat on a mission to rescue his son. The project was developed collaboratively by a three-person team using Git and GitHub for version control.

My role focused on programming the core gameplay logic and mechanics and integrating the different systems required for a functional and playable demo.
